# SQL-Server-Cleaning

## Project Overview
SQL Server project demonstrating data cleaning, data type conversion, table joins, and filtering healthcare diagnosis data using SQL queries.
This project demonstrates my experience using Microsoft SQL Server to clean and prepare healthcare data as part of my Health Informatics coursework at George Mason University.

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Skills Demonstrated
- Cleaning and organizing healthcare datasets
- Converting data types using `CAST()`
- Handling NULL and missing values
- Creating tables using `SELECT INTO`
- Using SQL queries to inspect and prepare data

## What I Learned
This project helped me develop foundational SQL skills and gain experience preparing healthcare datasets for further analysis.
